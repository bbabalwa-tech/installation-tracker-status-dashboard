Change the dashboard password

Use this page to set a new password for the Water Champions dashboard. Nothing you type here is sent anywhere; the access code is made on this computer.

Use at least 12 characters. Three or four ordinary words work well, for example "river blue kettle morning".

Your new access code

Now finish in Google Sheets

  1. Open the Dashboard Access Google Sheet.
  2. Click cell A2 (under "Access Code"), delete what is there, and paste the new code.
  3. Wait about a minute, then open the dashboard link and try the new password.
  4. Send the new password to the people who should still have access.

Everyone who used the old password will be asked for the new one the next time they open the dashboard.
